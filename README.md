# SoCal Cleanup & Hauling — Website

Business website for **SoCal Cleanup & Hauling**, a junk removal and yard cleanup service based in Yorba Linda & Orange County, CA.

## 🌐 Live Site
[socalcleanuphauling.netlify.app](https://socalcleanuphauling.netlify.app) ← update this once deployed

## 📋 Pages & Sections
- **Hero** — Tagline, CTA buttons, trust indicators
- **Services** — Junk Removal, Garage Cleanouts, Yard Cleanup, Furniture Hauling, Pet Waste, Moving Cleanups
- **Gallery** — Before/after job photos (placeholders until real photos are added)
- **Pricing & Service Area** — Pricing guide + cities served
- **Why Us** — Owner-operated, same-day, free quotes, no hidden fees
- **Contact Form** — Name, phone, address, service type, message, photo upload (Formspree)

## 🛠️ Tech Stack
- Pure HTML/CSS/JS — no frameworks, no dependencies
- [Formspree](https://formspree.io) for contact form submissions
- Hosted on GitHub Pages
